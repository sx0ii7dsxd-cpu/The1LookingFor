# The1LookingFor

A React + Vite starter for building a modern website with HTML, CSS, and a React front end. This project is ready for you to customize with your own sections, branding, and content.

## Scripts

- npm run dev — start the local development server
- npm run build — create a production build
- npm run preview — preview the production build locally

## Stack

- React
- Vite
- CSS
- Java 21 can be added later for the backend layer if needed
